# 08 用户使用指南

## 1. 快速入门

### 1.1 下载安装

- 打开华为应用市场（AppGallery），搜索「昇腾之家」或「AscendMate」
- 点击下载安装（HAP 安装包约 20MB，**内容已内置，无需额外下载**）
- 安装即用，**无需网络、无需登录、无需等待加载**
- 全部功能免费使用

> 💡 **第一次打开**：您将看到三段引导卡片介绍核心功能，滑到最后点击"开启昇腾之旅"即可进入首页。

### 1.2 界面总览

```
 ┌─────────────────────┐
 │ 🔍 搜索框          │   ← 输入关键词，全站搜索
 ├─────────────────────┤
 │  学习  场景  资源  │   ← 快捷分类入口
 ├─────────────────────┤
 │  推荐阅读（轮播）   │   ← 今日精选内容

 └─────────────────────┘
```

## 2. 核心功能

### 2.1 浏览学习路径

想要系统学习昇腾 AI？从「学习路径」开始：

1. 点击首页「学习」宫格 → 进入六阶段学习路径
2. 查看当前阶段进度，点击进入章节阅读
3. 读完一章，自动标记「已完成」
4. 全部完成第六章 → 获得「昇腾入门」成就

### 2.2 技术导航

快速找到特定技术文档：

1. 底部 Tab「知识库」→ 三分类入口（学习/场景/资源）
2. 下方「技术导航」→ 展开/折叠的卡片列表
3. 点击任意技术分类 → 子目录列表 → 选择文章

### 2.3 全文搜索

1. 点击首页顶部搜索框，或底部「搜索」Tab
2. 搜索框会显示示例搜索词（如 `npu-smi`、`CANN 安装`），**点击即可搜索**
3. 输入关键词（如 `FAQ`、`PyTorch`、`报错信息`），本地索引毫秒级返回结果
4. 结果按相关性排序，可点分类标签筛选
5. 点击结果进入文章，关键词自动高亮

**搜索技巧**：
- 搜索「FAQ」快速查看常见问题
- 搜索命令名如 `npu-smi` 直达对应文档
- 搜索报错信息片段可找到解决方案
- **所有搜索均在本机完成**，无需网络

### 2.4 收藏文章

1. 打开任何文章，点击底部「♡」按钮（伴随弹性动效反馈）
2. 选择收藏夹，或新建一个
3. 收藏的文章可在「我的 → 收藏夹」中统一查看
4. 收藏自动保存在本地，**不需要网络**

### 2.5 阅读设置

在「我的 → 设置 → 阅读设置」中：

| 设置项 | 说明 |
|--------|------|
| 字体大小 | S / M / L / XL 四档 |
| 主题模式 | 跟随系统 / 浅色 / 深色 |
| 代码行号 | 显示/隐藏 |
| 自动滚动 | 开启朗读模式自动滚动 |

## 3. 进阶操作

### 3.1 桌面 Widget（卡片）

1. 长按桌面空白处 → 点击「服务卡片」
2. 找到「昇腾之家」→ 选择卡片样式
3. 添加到桌面：
   - **2×1 快捷搜索**：一键搜索
   - **2×2 今日推荐**：每日精选
   - **4×2 学习进度**：学习跟踪
4. 点击卡片直达 APP 内对应页面

### 3.2 元服务（免安装使用）

- 在应用市场搜索「昇腾之家 元服务」添加到桌面
- 无需安装 APP，即可直接搜索和阅读文章
- 元服务占空间 < 5MB

### 3.3 多端同步（登录华为账号后）

1. 在设置中开启「多端同步」
2. 手机和平板登录同一华为账号
3. 手机读一半的文章 → 平板打开 → 自动提示「继续上次进度」
4. 收藏夹和设备间实时同步

## 4. 常见操作 FAQ

### Q: 这个 APP 需要联网吗？

**A**: 不需要。昇腾之家的全部内容都随安装包内置在手机中，启动、浏览、搜索全部在本机完成，**不申请任何网络权限**。在无信号的地铁、机房、出差途中均可正常使用。

### Q: 内容会更新吗？

**A**: 会。内容随 APP 版本更新一起发布。当上游 AscendMate 资料栈更新后，开发团队会重新构建打包并发布新版本，您升级 APP 即获得最新内容。

### Q: 是否可以分享文章给同事？

**A**: 可以。在文章页点击右上角「分享」按钮，选择分享到微信、WeLink、笔记应用等。分享的链接指向在线文档版本（对方需联网访问），您在本机阅读不受影响。

### Q: 怎么反馈问题或提建议？

**A**: 进入「我的 → 关于昇腾之家 → 反馈」或直接给项目提 Issue：[GitHub Issues](https://github.com/RevolutionLA/AscendMate/issues)

### Q: 支持平板吗？

**A**: 支持。平板打开自动适配为分栏布局：左侧目录 + 右侧正文，阅读体验更佳。

## 5. 常见页面操作指引

### 文章页面

```
操作区域：顶部导航栏
- ← 返回按钮
- 📋 文章目录（悬浮层，带锚点跳转）
- 🔗 分享
- Aa 字号调节

操作区域：底部操作栏
- ♡ 收藏/取消收藏
- 📋 目录（快速跳转）
- Aa 字号
- ↗ 分享
```

### 列表页面

```
- 点击 → 进入文章
- 长按 → 弹出菜单（收藏/复制链接/分享）
```

## 6. 卸载说明

- 进入「设置 → 应用和服务 → 应用管理 → 昇腾之家」→ 卸载
- 卸载后所有本地数据（包括收藏、进度、偏好）一同清除，无云端残留
- 重新安装后为干净初始状态
