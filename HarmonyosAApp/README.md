## 背景说明

AscendMate（昇腾之家）目前已有：

- **GitHub 仓库**：[RevolutionLA/AscendMate](https://github.com/RevolutionLA/AscendMate) — VitePress 静态文档站，面向桌面端
- **在线网页**：[revolutionla.github.io/AscendMate](https://revolutionla.github.io/AscendMate/) — 完整的昇腾资料栈，按场景组织、支持全文搜索
- **Ascend Assistant**：面向昇腾服务器的 AI 辅助 Skill

本 APP 旨在将上述桌面端内容栈延伸到手机端，以鸿蒙原生 APP 的形式提供极致移动体验。
