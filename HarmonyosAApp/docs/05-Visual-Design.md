# 05 视觉设计方案

## 1. 视觉方向

### 1.1 设计语言定位

**「深空科技 · 冷静可靠」**

以深空蓝为基底，昇腾蓝为灵魂，科技青为点缀，构建一套冷静、专业、有科技质感的视觉语言。灵感来源于：夜空星辰下的数据中心 + 昇腾 NPU 芯片的流光质感。

### 1.2 关键词

**深沉、通透、精致、专业** — 不做花哨的渐变，用光与空间传递品质感。

## 3. 图标系统

### 3.1 TabBar 图标

| Tab | 填充态 | 线性态 | 说明 |
|-----|--------|--------|------|
| 首页 | 房子（实心） | 房子（描边） | 使用 Symbol 字体 |
| 知识库 | 书籍（实心） | 书籍（描边） | |
| 搜索 | 放大镜（实心） | 放大镜（描边） | |
| 我的 | 人形（实心） | 人形（描边） | |

### 3.2 功能图标

- **风格**：线性描边（stroke-width: 2），圆角端点
- **颜色**：默冷灰-3，选中/强调为昇腾蓝
- **尺寸**：导航 24dp，列表前导 20dp，标签内 16dp
- **来源**：优先使用 HarmonyOS Design Icons 系统图标
- **补充**：AscendMate 品牌定制图标（昇腾 Logo 变形、NPU 芯片抽象）

## 4. 动效设计

### 4.1 页面转场

| 场景 | 动效 | 时长 |
|------|------|------|
| Tab 切换 | 淡入 + 位移 8dp（从右至左） | 300ms |
| 进入文章详情 | 页面从右侧滑入（Push） | 350ms |
| 返回 | 页面从左侧滑出 | 300ms |
| 搜索结果 | 列表项逐行淡入（stagger） | 200ms each |
| 收藏/取消收藏 | 图标缩放脉冲 + 心形填充 | 200ms |

### 4.2 微交互

| 元素 | 动效 |
|------|------|
| 搜索框聚焦 | 搜索框宽度扩展 + 光晕渐显 |
| 按钮点击 | `scale(0.96)` 弹缩 |
| 卡片点击 | `scale(0.98)` + 阴影加深 |
| 文章加载 | 骨架屏（skeleton screen）渐显 |
| 底部弹出浮层 | 从底部上滑（带动画曲线 cubic-bezier 0.2,0,0,1） |
| 返回顶部 | 平滑滚动 |

## 5. 空状态 / 异常状态设计

| 状态 | 插画 + 文案 | 操作 |
|------|-----------|------|
| 无搜索结果 | 放大镜+「未找到相关内容」 | 建议换个关键词 |
| 收藏夹为空 | 空星星+「还没有收藏的内容」 | 「去浏览」按钮 |
| 无网络 | 信号断开+「网络已断开」 | 「重试」按钮 |
| 加载失败 | 感叹号+「加载失败」 | 「点击重试」 |
| 阅读历史为空 | 时钟+「还没有阅读记录」 | 「去首页看看」 |
