# 09 设计评审清单（交付给开发团队）

> 本清单用于设计定稿后的团队评审与开发前的最终确认。逐项核对，全部通过后才能进入编码阶段。

## 1. 产品层

- [ ] 产品定位明确：移动端昇腾资料阅览门户（不做运维实操）
- [ ] 目标用户与使用场景已达成共识（学习者/运维/算法/决策者）
- [ ] P0 功能范围冻结（首页、浏览、搜索、导航、收藏）
- [ ] 与网页/仓库的关系明确（内容是 OTA 更新，非独立维护）
- [ ] 阶段划分（MVP → 增强 → 鸿蒙特性）确认

## 2. 信息架构层

- [ ] 底部 4 Tab 结构确认（首页/知识库/搜索/我的）
- [ ] 知识库三分类（学习/场景/资源）+ 技术导航映射确认
- [ ] 全部文章完成分类归属
- [ ] 文章详情页的上一篇/下一篇逻辑定义
- [ ] 目录结构可支持未来新增内容（无需改代码）

## 3. 交互层

- [ ] 全局手势（侧滑返回/下拉刷新/长按菜单）确认
- [ ] 所有页面转场动效时长记录
- [ ] 空状态/错误状态/加载状态有统一设计
- [ ] 弱网模式表现定义
- [ ] 文章阅读进度保存时机确认（滚动停止 2s / 离开页面）
- [ ] 收藏/取消收藏反馈（Toast + 撤销）
- [ ] 键盘弹出输入框不被遮挡
- [ ] 触觉反馈触发点清单

## 4. 视觉层

- [ ] 色彩 Token 与深色模式映射表冻结
- [ ] 字体层级表确认（含阅读字号 4 档）
- [ ] 间距体系（4 点网格）统一
- [ ] 卡片/列表/按钮组件样式统一
- [ ] 代码块深浅配色方案确认
- [ ] 图标资源到位（Tab 4 套 × 2 态 + 功能图标）
- [ ] 品牌 Logo / 启动图 / 应用图标到位

## 5. 鸿蒙特性层

- [ ] 桌面 Widget（2 款以上）尺寸与内容确认
- [ ] 元服务范围确定（搜索 + 速览）
- [ ] 深色模式跟随系统方案确认
- [ ] 多端同步（可选）技术预研结论
- [ ] 意图框架（可选）接入范围确认
- [ ] 折叠屏/平板响应式布局策略确认

## 6. 技术层

- [ ] Markdown 渲染器选型确认（自研 ArkTS 渲染）
- [ ] 搜索方案（本地倒排索引）确认
- [ ] 内容更新通道（内置 + OTA）确认
- [ ] 数据存储方案（RDB/文件缓存）确认
- [ ] 性能基线（冷启动/渲染/搜索）明确
- [ ] 权限清单最小化确认
- [ ] ArkTS 工程结构模板创建

## 7. 交付流程

- [ ] 设计稿（Figma）交付完整标注
- [ ] 设计 Token JSON 导出
- [ ] 图标 SVG 资源打包
- [ ] 数据模型/接口伪代码评审
- [ ] 测试用例初稿完成（功能/兼容/性能/无障碍）
- [ ] 发布渠道（AGC）账号与签名准备
