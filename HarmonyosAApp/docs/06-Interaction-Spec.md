# 06 交互设计规格

## 1. 交互设计原则

| 原则 | 说明 |
|------|------|
| **拇指域优化** | 高频操作按钮置于屏幕中下区域（拇指可及半径） |
| **可见性** | 关键功能一次点击可见，不藏在深层菜单 |
| **即时反馈** | 所有操作 100ms 内给出视觉反馈 |
| **可逆性** | 收藏/删除均有可撤销操作 |
| **容错性** | 搜索输入容错（错别字提示、联想纠正） |

## 2. 手势体系

### 2.1 核心手势

| 手势 | 操作 |
|------|------|
| 单指点击 | 选择、打开 |
| 单指长按 | 弹出上下文菜单（收藏/分享/复制链接） |
| 单指滑动 | 页面滚动（阻尼效果） |
| 左滑 | 返回上一页（全局侧滑返回） |
| 右滑 | 前进（浏览历史） |
| 双指缩放 | 图片查看、代码块放大 |
| 下拉 | 列表页刷新 |
| 上拉 | 加载更多 |

### 2.2 手势与页面映射

| 页面 | 手势行为 |
|------|----------|
| 首页 | 下拉刷新推荐内容 |
| 文章详情 | 左滑返回；下滑调出目录浮层（边缘触发） |
| 列表页 | 长按文章项 → 弹出操作菜单 |
| 搜索页 | 清空按钮 X；下滑收起键盘 |
| 我的 | 长按缓存条目删除 |

## 3. 导航模型

### 3.1 Tab 导航行为

| 行为 | 实现 |
|------|------|
| Tab 点击 | 切换页面 + 触感反馈 |
| 当前 Tab 双击 | 回滚到页面顶部 |
| 当前 Tab 再点击（已顶部） | 触发刷新 |
| Tab 长按 | 显示快捷操作（首页→搜索；知识库→最近浏览） |

### 3.2 页面栈

```
[Navigation] 鸿蒙系统路由
├── 首页 (根)
│   ├── 分类列表
│   │   └── 文章详情
│   └── 搜索结果 → 文章详情
├── 知识库 (根)
│   ├── 分类详细页
│   └── 学习路径 → 学习详情
├── 搜索 (根)
│   └── 搜索结果 → 文章详情
└── 我的 (根)
    ├── 收藏夹 → 文章详情
    ├── 阅读历史 → 文章详情
    ├── 学习进度 → 学习详情
    ├── 设置 → 阅读设置/关于
    └── 离线缓存 → 管理页
```

## 4. 关键交互流程

### 4.1 搜索流程

```
用户输入 "vllm"
    ↓
搜索页实时联想（防抖 300ms）
    ↓
选择联想项 / 回车
    ↓
展示结果（标题+摘要+路径+关键词高亮）
    ├─ 结果过多 → 顶部分类筛选标签（全部/环境/训练/推理...）
    ├─ 无结果 → 提示更换关键词 + 热搜推荐
    ↓
点击结果 → 文章详情（关键词滚动定位并高亮 3 秒）
    ↓
右侧底栏 → 收藏/分享/调整字号
```

### 4.2 学习路径流程

```
首页宫格点击「学习」
    ↓
学习路径总览（六阶段进度环）
    ↓
点击阶段卡 → 阶段详情页（章节列表 + 完成状态）
    ↓
点击章节 → 文章阅读
    ├─ 阅读完毕（滑到底部）→ 弹「标记为已完成？」确认
    ↓
返回阶段页 → 章节显示 ✓，进度更新
    ↓
六阶段全部完成 → 学习证书页面（可分享）
```

### 4.3 收藏流程

```
文章页面 → 点击底栏 ♡
    ↓
未创建收藏夹 → 弹「新建收藏夹」输入框（默认名「默认收藏夹」）
    ↓
已创建 → 直接收藏（Toast「已收藏」）或弹选择收藏夹
    ↓
再次点击 ♡ → 取消收藏（Toast「已取消」+「撤销」按钮 3 秒）
```

## 5. 状态反馈

### 5.1 加载状态

| 状态 | 表现 |
|------|------|
| 首屏加载 | 骨架屏（卡片灰块渐闪） |
| 列表加载更多 | 底部转圈 + 「加载中...」 |
| 图片加载 | 占位灰底 + 淡入 |
| OTA 更新 | 顶栏进度条（或状态栏通知） |

### 5.2 空状态 & 错误状态

统一遵循 05 文档第 5 节的空状态设计。

## 6. 触觉反馈

| 触发 | 反馈 |
|------|------|
| Tab 切换 | 轻触觉（`Haptics.Impact.Light`） |
| 收藏/下载成功 | 中触觉 + 伴随音效 |
| 错误操作 | 重触觉（`Haptics.Impact.Heavy`） |
| 长按呼出菜单 | 轻触觉 |

## 7. 无障碍交互

- 全功能支持键盘导航（外接键盘方向键+TAB）
- 动态字体（系统字体缩放 100%-200% 内容不破坏）
- 对比度适配（见 03 无障碍设计）
- 交互目标最小尺寸 44×44dp（代码块复制按钮 40dp 可忽略）

## 8. 交互验收清单

- [ ] 所有底部操作在单手模式下可触达（拇指域）
- [ ] 页面转场无明显卡顿（< 16ms 帧渲染）
- [ ] 所有弹窗在 3G 弱网下仍有明确反馈
- [ ] 无永久静默失败的场景（错误均有重试）
- [ ] 键盘弹出时输入框不被遮挡（`adjustPan` 模式）
- [ ] 深色模式切换无闪烁
- [ ] 阅读进度即使强制退出也能恢复
