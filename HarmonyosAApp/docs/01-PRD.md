# 01 产品需求文档（PRD）

## 1. 产品背景

### 1.1 现状分析

AscendMate 目前以 VitePress 静态文档站的形式托管在 GitHub Pages 上，提供了完善的昇腾智算生态技术资料，涵盖：

- 学习路径（六阶段 AI 入行体系）
- 环境搭建（7 步从裸机到可跑代码）
- 模型训练（LLaMA-Factory 微调、MindSpeed 预训练）
- 模型推理（MindIE、vLLM-Ascend、SGLang、Dify）
- 算子开发（Ascend C、Triton、CATLASS）
- 运维监控（Prometheus + Grafana NPU 大屏）
- 场景价值（金融、医疗、政务、制造行业方案）
- 算力运营管理（利用率、调度、成本核算）
- 资源导航与 FAQ

现有平台为**桌面端优先**，在手机浏览器上阅读体验不佳：导航拥挤、代码块溢出、全文搜索入口不便。

### 1.2 机会

- 昇腾开发者群体日益增长，移动端碎片时间学习需求旺盛
- 运维和交付人员经常在工作现场需要快速查资料，手机是最佳终端
- HarmonyOS NEXT（纯血鸿蒙）生态日趋成熟，原生 APP 体验远优于 Web 壳
- 鸿蒙的元服务、Widget、多端协同能力可创造区别于普通 APP 的独特体验

## 2. 产品目标

构建一款**鸿蒙原生 APP**，将 AscendMate 资料栈无缝迁移到手机端，同时利用鸿蒙特性提供超越 Web 浏览的用户体验。

### 核心目标

| 维度 | 目标 |
|------|------|
| **信息获取** | 用户在手机上可快速浏览、搜索、收藏昇腾全栈技术资料 |
| **碎片化学习** | 支持学习路径跟踪、阅读进度保存，方便通勤/间隙时间学习 |
| **现场运维辅助** | 运维人员可在现场快速查阅 FAQ、命令手册、运维 SOP |
| **沉浸阅读** | 代码块适配手机屏幕展示优化，Markdown 渲染精致 |
| **鸿蒙原生** | 充分利用元服务、Widget、多端协同等鸿蒙特性 |

### 非目标

- 不做昇腾服务器直接管理功能（保留给 Ascend Assistant Skill）
- 不做实时 NPU 监控仪表盘（保留给 Grafana 移动端）
- 不支持离线全量下载（支持智能缓存 + 收藏离线）

## 3. 目标用户

### 用户画像

| 画像 | 角色 | 使用场景 | 核心需求 |
|------|------|----------|----------|
| **AI 学习者** | 从零入行 AI 的学生/转行者 | 通勤学知识、睡前看教程 | 学习路径引导、阅读进度、收藏 |
| **运维工程师** | 昇腾服务器交付/运维人员 | 现场排查问题、查命令 | 快速搜索、FAQ、离线访问 |
| **算法工程师** | 模型训练/推理开发 | 午休时查资料、确认参数 | 精准搜索、代码参考、书签 |
| **业务决策者** | 项目经理、产品负责人 | 了解昇腾能力、看行业场景 | 场景案例浏览、能力概览 |

## 4. 功能需求

### 4.1 核心功能（P0 - 必须）

| 功能模块 | 功能描述 | 优先级 |
|----------|----------|--------|
| **首页推荐** | 精选内容轮播 + 分类快捷入口 | P0 |
| **内容浏览** | Markdown 渲染阅读器，支持代码块缩放/复制，图片缩放 | P0 |
| **全文搜索** | 本地模糊搜索 + 标签筛选，支持按分类限定搜索范围 | P0 |
| **导航菜单** | 底部 Tab 导航 + 侧边栏内容目录树 | P0 |
| **收藏/书签** | 收藏文章到自定义收藏夹，支持离线阅读 | P0 |

### 4.2 重要功能（P1 - 重要）

| 功能模块 | 功能描述 | 优先级 |
|----------|----------|--------|
| **学习路径** | 六阶段学习路径展示、进度跟踪（已读/未读标记） | P1 |
| **阅读历史** | 浏览历史记录、最近阅读续读 | P1 |
| **离线缓存** | 智能缓存频繁访问页面，收藏内容离线保存 | P1 |
| **深色模式** | 跟随系统/手动切换深色主题 | P1 |
| **字体调节** | 支持正文字体大小滑块调节 | P1 |
| **代码一键复制** | 代码块右上角复制按钮，格式化粘贴 | P1 |

### 4.3 增强功能（P2 - 锦上添花）

| 功能模块 | 功能描述 | 优先级 |
|----------|----------|--------|
| **桌面 Widget** | 快捷搜索/今日推荐/学习进度卡片 | P2 |
| **元服务卡片** | HarmonyOS 元服务，免安装直达搜索/文章 | P2 |
| **多端协同** | 手机/平板/PC 阅读进度同步 | P2 |
| **一键跳转** | 文章中的外部链接一键唤起浏览器/GitHub | P2 |
| **分享** | 通过系统分享菜单分享文章链接 | P2 |
| **关键词高亮** | 搜索结果在文章内高亮显示 | P2 |
| **目录锚点导航** | 长文章内快速跳转章节 | P2 |

## 5. 数据需求与内容源

### 5.1 内容来源

APP 内容全量基于现有 AscendMate 文档站 Markdown 源文件：

| 数据项 | 来源 | 更新方式 |
|--------|------|----------|
| 文档内容 | GitHub 仓库 `docs/` 目录 | OTA 增量更新 |
| 目录结构 | VitePress 侧边栏配置 | 随文档更新 |
| 搜索索引 | 本地构建倒排索引 | 增量索引更新 |
| 图片资源 | GitHub 仓库 `docs/public/` 目录 | 按需缓存 |

### 5.2 本地数据

| 数据项 | 存储方式 | 说明 |
|--------|----------|------|
| 收藏夹 | 本地数据库（ArkData） | 支持自定义文件夹 |
| 阅读进度 | 本地数据库 | 按文章记录阅读位置 |
| 搜索历史 | 本地数据库 | 最近 50 条 |
| 缓存内容 | 文件系统沙箱 | LRU 自动淘汰 |
| 用户偏好 | Preferences | 字体大小、主题、语言等 |

## 6. 阶段规划

### 阶段一：MVP（6-8 周）

- [ ] 底部 Tab 导航 + 内容页面框架搭建
- [ ] Markdown 渲染阅读器
- [ ] 首页内容展示
- [ ] 全文搜索（本地模糊搜索）
- [ ] 导航目录树
- [ ] 深色模式
- [ ] GitHub OTA 内容更新

### 阶段二：体验增强（4-6 周）

- [ ] 收藏/书签功能
- [ ] 阅读历史与续读
- [ ] 学习路径与进度追踪
- [ ] 字体大小调节
- [ ] 代码块优化（一键复制、横向滚动）
- [ ] 离线缓存策略

### 阶段三：鸿蒙特性（4-6 周）

- [ ] 桌面 Widget（搜索/推荐/学习进度）
- [ ] 元服务卡片
- [ ] 多端协同（阅读进度同步）
- [ ] 意图框架集成

## 7. 关键指标（OKR）

| 指标 | 目标值 | 衡量方式 |
|------|--------|----------|
| DAU | 上线首月 > 500 | 友盟/鸿蒙统计 |
| 搜索使用率 | 每日活跃用户中 > 30% 使用搜索 | 埋点 |
| 人均浏览页数 | > 5 页/天 | 埋点 |
| 收藏转化率 | 浏览用户中 > 15% 使用收藏 | 埋点 |
| 页面加载速度 | 首屏 < 1.5s，内容页 < 800ms | 性能监控 |
| 满意度评分 | App Store 评分 > 4.5 | 应用市场 |
