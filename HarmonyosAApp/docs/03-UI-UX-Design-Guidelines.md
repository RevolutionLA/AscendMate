# 03 UI/UX 设计规范

## 1. 设计系统

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **内容为王** | 视觉服务于阅读，不喧宾夺主 |
| **触控优先** | 所有交互元素 ≥ 44pt 触控面积 |
| **一致性** | 全局统一的设计语言、组件、动效节奏 |
| **可访问性** | 满足 WCAG 2.1 AA 级对比度要求 |

### 1.2 品牌色板

## 2. 排版（Typography）

### 2.1 字体

- **中文**：HarmonyOS Sans（鸿蒙系统字体，系统内置）
- **英文/数字**：HarmonyOS Sans + IBM Plex Mono（代码）
- **代码**：HarmonyOS Mono / IBM Plex Mono

### 2.2 字号层级

| 用途 | 字号 | 字重 | 行高 |
|------|------|------|------|
| 大标题（文章标题） | 24sp | Bold (700) | 32sp |
| 页面标题（导航栏） | 18sp | Medium (500) | 24sp |
| 卡片标题 | 16sp | Medium (500) | 22sp |
| 正文 | 15sp | Regular (400) | 24sp |
| 次级正文 | 13sp | Regular (400) | 20sp |
| 辅助文字 | 12sp | Regular (400) | 16sp |
| 代码正文 | 13sp | Regular (400) | 20sp |
| Tab 标签 | 10sp | Medium (500) | 14sp |

### 2.3 文章正文字号调节

- 提供 4 级字号调节：S(14sp) / M(15sp) / L(17sp) / XL(19sp)
- 默认 M(15sp)
- 设置在「我的 > 设置 > 阅读设置」中调节

## 3. 间距与布局

### 3.1 间距体系（4 点网格）

| Token | dp | 用途 |
|-------|----|------|
| `--space-xs` | 4 | 图标与文字间 |
| `--space-sm` | 8 | 组件内部间隙 |
| `--space-md` | 12 | 列表项内间距 |
| `--space-lg` | 16 | 卡片内边距/列表间距 |
| `--space-xl` | 20 | 区块间距 |
| `--space-2xl` | 24 | 大区块间距 |
| `--space-3xl` | 32 | 页面边距 |

## 4. 组件系统（Component Library）

### 4.1 导航组件

| 组件 | 样式 | 说明 |
|------|------|------|
| 底部 TabBar | 4 Tab，图标+文字 | 选中态：昇腾蓝填充 / 未选中：冷灰-3 |
| 顶部导航栏 | 56pt，毛玻璃 | 左：返回/菜单、中：标题、右：操作（目录/分享/字号） |
| 侧边栏 | 从左侧滑出 | 技术导航目录树，可展开/折叠 |
| 标签页（Tabs） | 横滑 | 知识库分类切换、学习路径阶段切换 |

### 4.2 信息展示组件

| 组件 | 样式 | 说明 |
|------|------|------|
| 首页宫格 | 3×2 或 2×3，圆角卡片 | 快捷入口，带图标+背景渐变色 |
| 文章列表项 | 左标题+右箭头/缩略图 | 附带标签和阅读时间 |
| 精选卡片 | 横滑，带封面图 | 首页推荐位，全宽圆角 |
| 生态图标行 | 横滑行，Logo 图 | MindIE、vLLM 等生态组件入口 |
| 学习进度卡片 | 带环状进度 | 学习路径首页展示 |
| 章节目录树 | 缩进列表，可展开 | 技术导航/文章目录 |

### 4.3 交互组件

| 组件 | 样式 | 说明 |
|------|------|------|
| 搜索框 | 圆角 20dp，带搜索图标 | 首页顶部 + 搜索页 |
| 搜索历史 | 横向标签 | 可清除 |
| 收藏按钮 | 心形/星形图标 | 文章页底栏 |
| 代码块 | 深色背景圆角卡片 | 右上角复制按钮，可横向滚动 |
| Toast | 底部弹出 | 操作反馈 |
| 底部动作面板 | 圆角浮层 | 分享、更多操作 |

## 6. 无障碍设计

- 所有可交互元素提供 `accessibilityLabel`
- 对比度 ≥ 4.5:1（正文）/ 3:1（大文本）
- 支持系统动态字体缩放适配
- 支持 TalkBack 屏幕阅读器
- 触控热区 ≥ 44×44dp

## 7. 设计输出规范

- 使用 Figma 制作设计稿，组件级关联
- 输出标注：间距、字号、色值、圆角
- 动态交互输出 Prototype 动效原型
- 交付物包括：设计系统（Design Token）JSON、图标 SVG、组件库
