# 04 鸿蒙原生特性应用方案

> 本 APP 的独特价值在于深度融入 HarmonyOS NEXT 生态。本文件定义所有要应用的鸿蒙原生能力及使用场景。

## 1. 鸿蒙特性应用全景

```
HarmonyOS NEXT 特性 → AscendMate 落地点
├── 1. 元服务（Atomic Services）     → 免安装直达核心内容
├── 2. 桌面 Widget（ArkTS Widget）   → 学习进度/今日推荐/快捷搜索
├── 3. 多端协同（分布式数据）        → 手机/平板/PC 阅读进度同步
├── 4. 应用接续（Continuation）      → 手机上读一半，平板上接着读
├── 5. 意图框架（Intent Kit）        → 系统级搜索直达 APP 内容
├── 6. 深色模式（系统级）            → 跟随系统自动切换
├── 7. 安全与隐私（最小权限）        → 数据只存本地，可一键销毁
├── 8. 系统分享（服务面板）          → 一键分享到微信/笔记应用
├── 9. 华为账号（可选）              → 云同步收藏夹
├── 10. AI 能力（系统级）            → 智慧搜索建议、语音搜索
└── 11. 折叠屏/平板适配              → 响应式分栏布局
```

## 2. 元服务（Atomic Services）

### 2.1 概念

元服务是 HarmonyOS 上的第二种应用形态，特性为**免安装、即点即用**。用户点击元服务卡片/链接即打开，用完退出，无需下载安装包。

### 2.2 落地场景

| 元服务 | 功能 | 入口 |
|--------|------|------|
| **搜索直达** | 免安装搜索昇腾资料 | 桌面搜索、系统搜索、碰一碰 |
| **文章速览** | 免安装阅读特定文章 | 分享链接、扫描二维码 |
| **FAQ 助手** | 快速查常见问题 | 桌面卡片、控制中心 |

### 2.3 设计要点

- 元服务与主 APP 共享代码库（工程级复用），降低维护成本
- 元服务体积目标 < 5MB，首屏加载 < 1s
- 主要承载「搜索」与「单一文章阅读」两个高频轻场景

## 3. 桌面 Widget（ArkTS Widget / Form）

### 3.1 卡片列表

| 卡片 | 尺寸 | 内容 | 刷新频率 |
|------|------|------|----------|
| **快捷搜索卡** | 2×1 | 搜索框 + 最近热搜 | 每小时 |
| **今日推荐卡** | 2×2 | 精选文章标题 + 封面 | 每日 |
| **学习进度卡** | 4×2 | 当前学习阶段 + 环状进度 | 实时 |
| **精华卡** | 2×2 | 今日最佳命令/技巧 | 每日 |

### 3.2 卡片规范

- 使用 ArkTS 声明式卡片（`FormExtensionAbility`）
- 卡片更新使用定时刷新（`updateDuration` + `onUpdateForm`）
- 卡片点击事件 → 拉起 APP 对应页面（`router.startAbility`）
- 卡片样式适配深色模式

## 4. 多端协同与接续

### 4.1 阅读进度同步

- 使用 **分布式数据服务（Distributed Data）**，将阅读进度、收藏夹同步到登录同账号的设备
- 手机读一半 → 平板打开 → 弹窗「继续上次进度？」
- 收藏夹跨设备实时同步

### 4.2 应用接续（Cross-Device Continuation）

- 支持在手势框 / 华为分享快捷键中「接续最近任务」
- 接续到平板时自动切换为分栏布局（侧栏目录 + 右侧正文）
- 设备为折叠屏时自动展开为横屏分栏

### 4.3 协作场景

- 用户可将当前 FAQ 页面流转到大屏（电视/智慧屏）展示给团队
- 支持「碰一碰」将手机上的代码块发送到电脑端编辑器（可选进阶）

## 5. 意图框架（Intent Kit）

### 5.1 能力

- APP 将内容以「意图」方式声明，系统可在以下场景触达用户：
  - 全局搜索（桌面下拉搜索「昇腾怎么装驱动」→ 直接显示 APP 内结果）
  - 小艺建议（根据时间/地点/习惯推荐相关文章）
  - 华为 AppGallery 内容推荐

### 5.2 声明方式

- APP 声明 `AppClone` 与 `Intent` 能力（config.json 中配置 skills.json）
- 搜索意图：携带关键词跳转到 APP 搜索结果页
- 阅读意图：携带文章路径直接打开文章

## 6. 深色模式

### 6.1 策略

- **跟随系统**：使用 `systemDarkMode` 自动切换
- **手动覆盖**：设置中提供「跟随系统 / 浅色 / 深色」三档
- 颜色全部通过 design token 映射，无硬编码色值（见 03 文档色板）

### 6.2 细节规范

- 图片素材提供深色适配（`SRGB` + `HDR` 双版本或透明背景+混合模式）
- 代码块深浅两套配色方案（浅色下深色代码块保留，深色模式下使用更暗背景）
- 切换动画使用系统原生过渡

## 7. 安全与隐私（最小权限）

### 7.1 权限清单

| 权限 | 用途 | 状态 |
|------|------|------|
| 网络访问 | 内容下载、OTA 更新 | 必需 |
| 本地存储 | 缓存、收藏、进度 | 自动（沙箱） |
| 位置 | 无 | 不申请 |
| 相机/麦克风 | 无 | 不申请 |
| 电话/联系人 | 无 | 不申请 |

### 7.2 隐私设计

- **零账号也可用**：全部核心功能（浏览/搜索/阅读）无需登录
- 华为账号仅用于「云同步」等进阶功能，用户可选开启
- 无任何第三方 SDK 数据上报（无广告 SDK）
- 提供「一键清理缓存」和「回忆注销入口」

## 8. 系统分享服务面板

- 文章页分享按钮调用系统分享面板
- 分享内容 `title + url` 格式（链接指向网站对应文章）
- 支持一键「复制纯文本链接」
- 支持分享卡片（生成精美卡片图，用于微信/群聊）

## 9. AI 系统能力（可选增强）

| 能力 | 场景 | 说明 |
|------|------|------|
| 智慧搜索 | 桌面搜索中文自然语言 → 跳转 APP 搜索结果 | 基于 Intent Kit |
| 语音搜索 | 按住搜索框语音输入 | 使用系统语音识别 |
| 小艺建议 | 预测用户想看的类目并推荐 | 学习习惯分析（本机） |

## 10. 折叠屏/平板适配

### 10.1 响应式策略

| 设备形态 | 布局 |
|----------|------|
| 手机（≤600vp） | 单栏：Tab 导航 + 全屏页面 |
| 折叠屏展开（600-840vp） | 分栏：侧边导航（胶囊形）+ 内容 |
| 平板（≥840vp） | 侧边栏 + 内容 + 可选详情三栏 |

### 10.2 技术实现提示

- 使用 `GridRow/GridCol` 响应式栅格
- 使用 `Navigation` 系统路由 + `SideBarContainer` 侧栏
- 断点监听：`mediaquery` 适配宽度变化
- 文章页在大屏下支持「左目录右正文」双栏
