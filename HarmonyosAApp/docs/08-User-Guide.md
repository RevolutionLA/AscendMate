# 08 用户使用指南

## 1. 快速入门

### 1.1 下载安装

- 打开华为应用市场（AppGallery），搜索「昇腾之家」或「AscendMate」
- 点击下载安装（HAP 安装包约 20MB）
- 首次安装后，自动下载离线内容包（约 10-30MB，建议在 Wi-Fi 环境）
- 无需注册登录即可使用全部核心功能

### 1.2 界面总览

```
 ┌─────────────────────┐
 │ 🔍 搜索框          │   ← 输入关键词，全站搜索
 ├─────────────────────┤
 │  学习  场景  资源  │   ← 快捷分类入口
 ├─────────────────────┤
 │  推荐阅读（轮播）   │   ← 今日精选内容
 ├─────────────────────┤
 │  继续阅读           │   ← 最近未读完的文章
 ├─────────────────────┤
 │  生态组件           │   ← MindIE / vLLM / SGLang 等
 ├─────────────────────┤
 │  热门推荐           │   ← 更多优质内容
 ├─────────────────────┤
 │ 🏠  📚  🔍  👤     │   ← 底部导航 Tab
 └─────────────────────┘
```

## 2. 核心功能

### 2.1 浏览学习路径

想要系统学习昇腾 AI？从「学习路径」开始：

1. 点击首页「学习」宫格 → 进入六阶段学习路径
2. 查看当前阶段进度，点击进入章节阅读
3. 读完一章，自动标记「已完成」
4. 全部完成第六章 → 获得「昇腾入门」成就

### 2.2 技术导航

快速找到特定技术文档：

1. 底部 Tab「知识库」→ 三分类入口（学习/场景/资源）
2. 下方「技术导航」→ 展开/折叠的卡片列表
3. 点击任意技术分类 → 子目录列表 → 选择文章

### 2.3 全文搜索

1. 点击首页顶部搜索框，或底部「搜索」Tab
2. 输入关键词（如 `npu-smi`、`CANN 安装`）
3. 实时显示联想结果，按回车确认搜索
4. 结果按相关性排序，可点分类标签筛选
5. 点击结果进入文章，关键词自动高亮

**搜索技巧**：
- 搜索「FAQ」快速查看常见问题
- 搜索命令名如 `npu-smi` 直达对应文档
- 搜索报错信息片段可找到解决方案

### 2.4 收藏文章

1. 打开任何文章，点击底部「♡」按钮
2. 选择收藏夹，或新建一个
3. 收藏的文章可在「我的 → 收藏夹」中统一查看
4. 收藏的文章自动缓存，支持离线阅读

### 2.5 阅读设置

在「我的 → 设置 → 阅读设置」中：

| 设置项 | 说明 |
|--------|------|
| 字体大小 | S / M / L / XL 四档 |
| 主题模式 | 跟随系统 / 浅色 / 深色 |
| 代码行号 | 显示/隐藏 |
| 自动滚动 | 开启朗读模式自动滚动 |

## 3. 进阶操作

### 3.1 桌面 Widget（卡片）

1. 长按桌面空白处 → 点击「服务卡片」
2. 找到「昇腾之家」→ 选择卡片样式
3. 添加到桌面：
   - **2×1 快捷搜索**：一键搜索
   - **2×2 今日推荐**：每日精选
   - **4×2 学习进度**：学习跟踪
4. 点击卡片直达 APP 内对应页面

### 3.2 元服务（免安装使用）

- 在应用市场搜索「昇腾之家 元服务」添加到桌面
- 无需安装 APP，即可直接搜索和阅读文章
- 元服务占空间 < 5MB

### 3.3 多端同步（登录华为账号后）

1. 在设置中开启「多端同步」
2. 手机和平板登录同一华为账号
3. 手机读一半的文章 → 平板打开 → 自动提示「继续上次进度」
4. 收藏夹和设备间实时同步

## 4. 常见操作 FAQ

### Q: 如何离线阅读？

**A**: 收藏的文章会自动缓存以供离线阅读。也可以进入「我的 → 离线缓存 → 管理」中手动选择需要离线保存的分类或文章。

### Q: 内容过期了怎么办？

**A**: APP 启动时自动检测新内容。也可以下拉首页或知识库列表手动刷新。设置中可查看「内容版本」和「最后更新时间」。

### Q: 是否可以分享文章给同事？

**A**: 可以。在文章页点击右上角「分享」按钮，选择分享到微信、WeLink、笔记应用等。分享链接指向 GitHub Pages 在线版本。

### Q: 怎么反馈问题或提建议？

**A**: 进入「我的 → 关于昇腾之家 → 反馈」或直接给项目提 Issue：[GitHub Issues](https://github.com/RevolutionLA/AscendMate/issues)

### Q: 支持平板吗？

**A**: 支持。平板打开自动适配为分栏布局：左侧目录 + 右侧正文，阅读体验更佳。

## 5. 常见页面操作指引

### 文章页面

```
操作区域：顶部导航栏
- ← 返回按钮
- 📋 文章目录（悬浮层，带锚点跳转）
- 🔗 分享
- Aa 字号调节

操作区域：底部操作栏
- ♡ 收藏/取消收藏
- 📋 目录（快速跳转）
- Aa 字号
- ↗ 分享
```

### 列表页面

```
- 下拉 → 刷新内容
- 点击 → 进入文章
- 长按 → 弹出菜单（收藏/复制链接/分享）
```

## 6. 卸载说明

- 进入「设置 → 应用和服务 → 应用管理 → 昇腾之家」→ 卸载
- 卸载后所有本地数据（包括缓存、收藏、进度）一同清除
- 如已开启多端同步，重新安装后可恢复同步数据
