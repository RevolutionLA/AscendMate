# 05 视觉设计方案

## 1. 视觉方向

### 1.1 设计语言定位

**「深空科技 · 冷静可靠」**

以深空蓝为基底，昇腾蓝为灵魂，科技青为点缀，构建一套冷静、专业、有科技质感的视觉语言。灵感来源于：夜空星辰下的数据中心 + 昇腾 NPU 芯片的流光质感。

### 1.2 关键词

**深沉、通透、精致、丝滑、专业** — 不做花哨的渐变，用光与空间传递品质感。

### 1.3 视觉对标

| 对标产品 | 借鉴点 |
|---------|--------|
| 华为阅读 | 沉浸式阅读氛围、翻页过渡动画 |
| Apple Books | 书架排布、毛玻璃导航栏的优雅感 |
| Notion 移动版 | 卡片质感、留白节奏、布局透气性 |
| 系统设置（iOS/鸿蒙） | 列表阻尼、转场方向感、物理回弹 |

> 整体品质感应达到 **"华为/Apple 一级应用水准"**，让用户第一眼就感觉「这个 APP 很用心」。

### 3.2 功能图标

- **补充**：AscendMate 品牌定制图标（昇腾 Logo 变形、NPU 芯片抽象）

## 4. 动效设计

### 4.1 页面转场

| 场景 | 动效 | 时长 | 备注 |
|------|------|------|------|
| Tab 切换 | 淡入 + 位移 8dp（从右至左），带方向感：右 Tab = 页面向左滑入 | 300ms | 明确方向感，消除"跳转后不认识"的困惑 |
| 进入文章详情 | 页面从右侧滑入（Push） | 350ms | |
| 返回 | 页面从左侧滑出 | 300ms | |
| 搜索展示结果 | 结果卡片逐行淡入 + 微弹起（stagger 间隔 50ms） | 200ms each | 本地搜索秒出，动效掩盖"瞬发"的生硬感 |
| 收藏/取消收藏 | 图标缩放脉冲 + 心形填充 + 弹性回位 | 300ms | |
| 引导页→首页 | 引导页淡出 + 首页从底部上移 20dp 淡入 | 500ms | 平滑过渡，不突兀 |

### 4.2 微交互

| 元素 | 动效 |
|------|------|
| 搜索框聚焦 | 搜索框宽度扩展 + 光晕渐显 |
| 按钮点击 | `scale(0.96)` 弹缩 |
| 卡片点击 | `scale(0.98)` + 阴影加深 |
| 文章加载 | 骨架屏（skeleton screen）渐显 |
| 底部弹出浮层 | 从底部上滑（带动画曲线 cubic-bezier 0.2,0,0,1） |
| 返回顶部 | 平滑滚动 |

### 4.3 动效曲线（统一使用）

```typescript
// 缓动曲线定义
const EaseInOut = cubicBezier(0.4, 0, 0.2, 1);    // 标准（适用于大部分转场）
const EaseOut = cubicBezier(0, 0, 0.2, 1);        // 退出（适用于离场）
const EaseIn = cubicBezier(0.4, 0, 1, 1);          // 进入（适用于进场）
const Spring = cubicBezier(0.34, 1.56, 0.64, 1);   // 弹性（收藏心跳、卡片弹起）
const Smooth = cubicBezier(0.2, 0, 0, 1);          // 超平滑（浮层上滑）
```

> 全 APP 统一使用上述 5 条曲线，**禁止自行发明曲线**，确保动效节奏一致。

### 4.4 动效设计原则

1. **不过度** — 动效服务于理解（方向感、层级感），不纯为炫技
2. **不等待** — 所有动效 ≤ 350ms，用户操作后立即可达
3. **不突兀** — 使用系统物理曲线，不违反自然惯性直觉
4. **有原因** — 每个动效有明确的指向意义（打开的、关闭的、强调的）

## 5. 空状态 / 异常状态设计

| 状态 | 插画 + 文案 | 操作 |
|------|-----------|------|
| 首页 | 无空状态（内容全内置，首页永远有内容） | — |
| 无搜索结果 | 放大镜+「未找到相关内容」+ 示例关键词推荐 | 「试试这些」 |
| 收藏夹为空 | 空星星+「还没有收藏的内容」 | 「去浏览」按钮 |
| 数据异常 | 感叹号+「数据异常」 | 「重启 APP」 |
| 阅读历史为空 | 时钟+「还没有阅读记录」 | 「去首页看看」 |

> ⚠️ **不再需要任何网络相关状态**（无「网络已断开」「加载失败重试」等），因为 APP 完全本地运行。

## 6. 首次启动引导页设计

> 引导页是用户对 APP 的「第一印象」，也是消除陌生感的关键。设计遵循：**少而精、信息密度低、每页一个核心信息 + 一张示意插画**。

### 6.1 引导页三页内容

| 页 | 主标题 | 副标题 | 插画示意 |
|----|--------|--------|---------|
| 1 | 昇腾之家 | 昇腾智算资料库 · 离线全内置 | 深空蓝底 + NPU 芯片光效（微动效粒子） |
| 2 | 装了就完整 | 全部内容安装即内置，无需联网 | 书本图标 + 底座（稳稳落地动效） |
| 3 | 想学 · 想查 · 想解决 | 学习路径 · 全文搜索 · 问题定位 | 三图标环绕 + 光晕 |

页面底部：分页指示点 + 「跳过」链接（右上角）+ 最后一页「立即开始」主按钮。
主按钮样式：升腾蓝渐变（`#0066FF → #3388FF`），圆角 24dp，带按压动效。

### 6.2 引导页视觉规格

| 项 | 值 |
|----|-----|
| 背景 | 深空蓝 `#0B1A3A` 全屏 + 底部微光晕 |
| 标题色 | 纯白，28sp Bold |
| 副标题色 | `rgba(255,255,255,0.75)`，15sp |
| 插画区 | 中央 60% 高度，Canvas 轻量动效 |
| 指示点 | 当前页升腾蓝填充，其他 `rgba(255,255,255,0.3)`，宽度 24dp 药丸形（当前页拉长） |
| 转场 | 横向滑屏 + 惯性、弹簧回弹 |

### 6.3 引导页进入/退出

- 仅在 `首次启动（未初见引导标志）` 时展示一次
- 设置页可「重新播放引导」
- 退出引导 → 首页渐显（0.5s 淡入 + 轻微上移 20dp）
