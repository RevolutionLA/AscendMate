# 04 鸿蒙原生特性应用方案

> 本 APP 的独特价值在于深度融入 HarmonyOS NEXT 生态。本文件定义所有要应用的鸿蒙原生能力及使用场景。

## 1. 鸿蒙特性应用全景

> ⚡ **重要前提：本 APP 为全离线应用**，不申请网络权限。以下所有鸿蒙特性均在「无网络、全本地」的前提下设计，不依赖任何远端服务。

```
HarmonyOS NEXT 特性 → AscendMate 落地点（全部离线可用）
├── 1. 元服务（Atomic Services）     → 免安装直达本地内容（卡片直接读 HAP 内资源）
├── 2. 桌面 Widget（ArkTS Widget）   → 学习进度/今日推荐/快捷搜索（数据全部来自本地）
├── 3. 多端协同（分布式数据）        → 手机/平板本地数据通过华为账号能力离线迁移/克隆
├── 4. 应用接续（Continuation）      → 手机上读一半，平板上接着读（本地路径接续）
├── 5. 意图框架（Intent Kit）        → 系统搜索直达 APP 内本地内容
├── 6. 深色模式（系统级）            → 跟随系统自动切换
├── 7. 安全与隐私（零权限）          → 数据只存本地，无需网络，无敏感权限
├── 8. 本地页面转场/动效（ArkUI）    → 系统级丝滑动效，60fps
├── 9. 多窗口/自由窗口              → 小窗阅读、分屏对照代码
├── 10. AI 能力（系统级，可选）      → 鸿蒙智慧搜索建议（本地内容命中）
└── 11. 折叠屏/平板适配              → 响应式分栏布局
```

## 2. 元服务（Atomic Services）

### 2.1 概念

元服务是 HarmonyOS 上的第二种应用形态，特性为**免安装、即点即用**。用户点击元服务卡片/链接即打开，用完退出，无需下载安装包。

### 2.2 落地场景

> 元服务与主 APP 共享同一份打包资源 —— 所有内容在安装元服务时一并内置，**无需联网读取**。

| 元服务 | 功能 | 入口 | 数据来源 |
|--------|------|------|----------|
| **搜索直达** | 免安装搜索昇腾资料 | 桌面搜索、系统搜索、碰一碰 | 本地打包索引 |
| **文章速览** | 免安装阅读特定文章 | 分享卡片、本机打开 | 本地打包内容 |
| **FAQ 助手** | 快速查常见问题 | 桌面卡片、控制中心 | 本地打包内容 |

### 2.3 设计要点

- 元服务与主 APP 共享代码库（工程级复用），降低维护成本
- 元服务体积目标 < 5MB，首屏加载 < 1s
- 主要承载「搜索」与「单一文章阅读」两个高频轻场景

## 3. 桌面 Widget（ArkTS Widget / Form）

### 3.1 卡片列表

> 所有卡片内容来自 APP 内置数据，**无需网络，即时展示**。

| 卡片 | 尺寸 | 内容 | 刷新策略 |
|------|------|------|----------|
| **快捷搜索卡** | 2×1 | 搜索框 + 预置示例搜索词 | 随系统刷新 |
| **今日推荐卡** | 2×2 | 本地精选文章标题 + 封面 | 随系统周期刷新 |
| **学习进度卡** | 4×2 | 当前学习阶段 + 环状进度 | 本地数据实时 |
| **精华卡** | 2×2 | 今日最佳命令/技巧（从本地库随机） | 随系统周期刷新 |

### 3.2 卡片规范

- 使用 ArkTS 声明式卡片（`FormExtensionAbility`）
- 卡片更新使用定时刷新（`updateDuration` + `onUpdateForm`）
- 卡片点击事件 → 拉起 APP 对应页面（`router.startAbility`）
- 卡片样式适配深色模式

## 4. 多端协同与接续（分布式文件/数据能力）

### 4.1 阅读进度同步（分布式数据，非云同步）

- 使用 HarmonyOS **分布式数据能力（同一华为账号 + 可信设备组）**，将阅读进度、收藏夹在手机/平板间直接同步
- **不依赖公网**：设备处于同一局域网或通过华为账号可信组直连，依然是「点对点」而非云
- 手机读一半 → 平板打开 → 弹窗「继续上次进度？」
- 收藏夹跨设备同步

### 4.2 应用接续（Cross-Device Continuation）

- 支持在手势框 / 华为分享快捷键中「接续最近任务」
- 接续到平板时自动切换为分栏布局（侧栏目录 + 右侧正文）
- 设备为折叠屏时自动展开为横屏分栏

### 4.3 协作场景

- 用户可将当前 FAQ 页面流转到大屏（电视/智慧屏）展示给团队
- 支持「碰一碰」将手机上的代码块发送到电脑端编辑器（可选进阶）
- 以上全部基于本地内容与端侧分布式能力，无需服务器

## 5. 意图框架（Intent Kit）

### 5.1 能力

- APP 将本地内容以「意图」方式声明，系统可在以下场景触达用户（**仅触发跳转，内容仍来自本地包**）：
  - 全局搜索（桌面下拉搜索「昇腾怎么装驱动」→ 直接显示 APP 内本地结果并可打开）
  - 小艺建议（根据习惯推荐 APP 内文章，点击直达本地内容）
  - 华为 AppGallery 内容推荐

### 5.2 声明方式

- APP 声明 `skills.json` 意图能力（config.json 配置）
- 搜索意图：携带关键词跳转到 APP 搜索结果页（结果来自本地索引）
- 阅读意图：携带文章路径直接打开本地文章

## 6. 深色模式

### 6.1 策略

- **跟随系统**：使用 `systemDarkMode` 自动切换
- **手动覆盖**：设置中提供「跟随系统 / 浅色 / 深色」三档
- 颜色全部通过 design token 映射，无硬编码色值（见 03 文档色板）

### 6.2 细节规范

- 图片素材提供深色适配（`SRGB` + `HDR` 双版本或透明背景+混合模式）
- 代码块深浅两套配色方案（浅色下深色代码块保留，深色模式下使用更暗背景）
- 切换动画使用系统原生过渡

## 7. 零权限设计（全离线不需要任何权限）

### 7.1 「最小权限」→「零权限」

本 APP 全离线运行，不需要任何运行时权限。具体对比：

| 权限 | 原始方案 | 新方案（全离线） |
|------|----------|-----------------|
| 网络访问 | 必需（OTA 更新） | **无需** — 不申请 |
| 本地存储 | 必需（缓存） | **自动沙箱** — 无需声明 |
| 位置 | 不申请 | 不申请 |
| 相机/麦克风 | 不申请 | 不申请 |
| 电话/联系人 | 不申请 | 不申请 |

### 7.2 隐私设计

- **零账号也可用**：全部核心功能（浏览/搜索/阅读/收藏）无需登录
- 华为账号仅用于「分布式进度迁移」等可选的增强功能，用户可完全忽略
- **无网络 = 无数据上报**，无需任何隐私协议或弹窗
- 无任何第三方 SDK
- 用户卸载时，所有本地数据随沙箱完整清除

## 8. 系统分享服务面板

- 文章页分享按钮调用系统分享面板
- 分享内容 `title + url` 格式（链接指向网站对应文章）
- 支持一键「复制纯文本链接」
- 支持分享卡片（生成精美卡片图，用于微信/群聊）

## 9. AI 系统能力（可选增强）

| 能力 | 场景 | 说明 |
|------|------|------|
| 智慧搜索 | 桌面搜索中文自然语言 → 跳转 APP 搜索结果 | 基于 Intent Kit |
| 语音搜索 | 按住搜索框语音输入 | 使用系统语音识别 |

## 10. 折叠屏/平板适配

### 10.1 响应式策略

| 设备形态 | 布局 |
|----------|------|
| 手机（≤600vp） | 单栏：Tab 导航 + 全屏页面 |
| 折叠屏展开（600-840vp） | 分栏：侧边导航（胶囊形）+ 内容 |
| 平板（≥840vp） | 侧边栏 + 内容 + 可选详情三栏 |

### 10.2 技术实现提示

- 使用 `GridRow/GridCol` 响应式栅格
- 使用 `Navigation` 系统路由 + `SideBarContainer` 侧栏
- 断点监听：`mediaquery` 适配宽度变化
- 文章页在大屏下支持「左目录右正文」双栏

## 11. 本地动效系统（ArkUI 原生能力）

> 鸿蒙 ArkUI 框架提供 GPU 硬件加速的声明式动画管线，是实现「精致丝滑高级」UI 的基础底座。

| 能力 | 应用场景 | 说明 |
|------|----------|------|
| 隐式动画（animateTo） | Tab 切换、页面转场 | 利用系统硬件加速，400ms 曲线自动插值 |
| 属性动画（animation） | 卡片悬停缩放、按钮按压态 | 按钮按压 `scale(0.96)`、松开回弹 |
| 过渡动画（Transition） | 页面进入/退出/共享元素 | 页面推入滑出、返回手势联动 |
| 弹簧曲线（Spring） | 收藏图标脉冲、搜索框扩展 | `response: 0.4, damping: 0.7` 自然弹性感 |
| 物理动画（Physics） | 列表越界回弹、滚动阻尼 | 模拟惯性越界回弹手感 |
| 粒子/发光（Canvas） | 庆祝动效、加载动效 | 阶段完成后全屏粒子特效 |

详见 [05-Visual-Design.md](./05-Visual-Design.md) 第 4 节「动效设计」的完整动效规格。
