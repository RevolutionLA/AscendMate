# 03 UI/UX 设计规范

## 0. 设计核心主张：消除陌生感的设计原则

> 一个从未打开过 AscendMate APP 的新用户，打开后 30 秒内应该完成第一次有意义的操作（搜索一个关键词 or 读完一篇文章），且全程无需帮助文档。

### 0.1 陌生感来自哪里，如何消除

| 陌生感来源 | 消除设计 |
|-----------|---------|
| **我不知道这个 APP 能做什么** | 首次启动 3 页引导卡片 + 首页"所见即所得"的内容骨架 |
| **我找不到想要的东西** | 搜索框预置示例词（`npu-smi` `CANN`），点一下就能搜 |
| **我不懂这些技术名词** | 首页宫格用场景化命名（"学 AI" "查命令" "看方案"），而非技术分类名 |
| **我不敢点，不知道点了会去哪里** | 卡片内容摘要直接可见、返回路径清晰、页面转场带方向感 |
| **我中途退出，再进来不知道读到哪了** | 首页「继续阅读」始终展示最近 3 篇，阅读位置精确恢复 |
| **我很怕联网加载/等待** | 首页冷启动 < 0.5s，所有内容本地直读，从无加载转圈 |

### 0.2 三个"第一次"的体验设计

| 情境 | 设计 |
|------|------|
| **第一次打开 APP** | 3 页引导卡片 → 首页自动展示推荐内容（无需任何操作） |
| **第一次搜索** | 搜索框预置 3 个热门示例关键词（"npu-smi" "CANN安装" "FAQ"），点击即搜 |
| **第一次阅读** | 首页卡片展示第一篇文章摘要 + 预计阅读时间，点击进入 → 目录浮层自动提示章节跳转 |

### 0.3 UI 精致感的定义

| 维度 | 标准 |
|------|------|
| **丝滑** | 页面转场 60fps、滚动阻尼感自然、手势跟手无延迟 |
| **精致** | 每个组件都有设计意图：圆角一致、间距统一、品牌色贯穿 |
| **高级** | 不过度装饰（不滥用渐变/阴影），用「空间留白 + 毛玻璃质感 + 微妙动效」传递品质 |

### 0.4 与其他华为系 APP 的对标

| APP | 借鉴要点 |
|-----|---------|
| 华为阅读 | 翻页动画、沉浸式阅读氛围 |
| 花瓣剪辑 | 操作反馈动效、按钮触感 |
| 系统设置 | 列表阻尼感、毛玻璃导航栏 |

## 1. 设计系统

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **内容为王** | 视觉服务于阅读，不喧宾夺主 |
| **触控优先** | 所有交互元素 ≥ 44pt 触控面积 |
| **一致性** | 全局统一的设计语言、组件、动效节奏 |
| **可访问性** | 满足 WCAG 2.1 AA 级对比度要求 |

## 5. 精致丝滑设计规范（UI Advanced Polish）

> 本章节定义 AscendMate UI 的「高级感」标准。只有达成本章全部规范，才算完成 UI 开发。

### 5.1 毛玻璃规范（Glassmorphism）

毛玻璃是 AscendMate 的**标志性材质**，应用在顶部导航栏和底部 TabBar。

| 参数 | 值 | 说明 |
|------|-----|------|
| 背景色 | 浅色：`rgba(255,255,255,0.72)` / 深色：`rgba(13,33,73,0.72)` | 半透明底色 |
| 模糊量 | `backdropFilter: blur(20px)` | 后方内容模糊半径 |
| 分割线 | 浅色：`rgba(226,230,236,0.5)` / 深色：`rgba(42,58,92,0.5)` | 0.5dp 半透明 |
| 阴影 | 浅色：`0 1px 8px rgba(0,0,0,0.06)` / 深色：无 | 柔光阴影 |

```
┌──────────────────────┐
│  ← 导航标题     📋 │  ← rgba(255,255,255,0.72) + blur(20px)
│  ▽▽▽ (下方内容半透) │     底部 0.5dp 分割线
└──────────────────────┘
```

### 5.2 动效体系（Motion Design）

| 动效类型 | 场景 | 详细参数 |
|---------|------|---------|
| **页面转场** | Tab 切换 | 淡入+位移 8dp，`cubicBezier(0.2,0,0,1)`，300ms |
| **Push/Pop** | 进入/返回文章 | Push：`translateX(100%→0)` / Pop：`translateX(0→-30%)`，350ms，`cubicBezier(0.4,0,0.2,1)` |
| **列表入场** | 搜索结果/列表页 | 逐项淡入 + 向上位移 12dp，stagger 间隔 60ms，各 250ms |
| **收藏动画** | 点击收藏 | 图标 `scale(1→0.7→1.15→1)` 脉冲 + 心形渐显填充，300ms，弹簧曲线 |
| **按压反馈** | 按钮/卡片点击 | `scale(0.96)` + 背景色加深 10%，100ms，松手回弹 150ms |
| **骨架屏** | 内容加载（极少发生） | 灰块闪烁：`opacity 0.3→0.7` 循环，800ms 周期 |
| **返回顶部** | 点击顶部指示 | 平滑滚动 300ms，`cubicBezier(0,0,0.2,1)` |
| **浮层出现** | 目录/分享面板 | 从底部上滑 + 背景 `opacity 0→0.4`，300ms，`cubicBezier(0.2,0,0,1)` |
| **庆祝动效** | 学习阶段完成 | 全屏粒子升起 + 徽章缩放展示，1.2s（详见 5.5） |

### 5.3 触摸反馈（触感与响应）

| 交互 | 视觉反馈 | 触觉反馈 | 时长 |
|------|---------|---------|------|
| 按钮按下 | `scale(0.96)` 弹缩 + 背景加深 | 轻触 | 100ms |
| 按钮抬起 | `scale(1.0)` 回弹 + 背景复原 | 无 | 150ms |
| 列表项点击 | 背景闪亮（`highlightColor`） | 轻触 | 80ms |
| 长按呼出菜单 | 选中项背景加深 + 抖动 | 中触 | 触发即振动 |
| 滑动手势 | 跟手阻尼（`drag: 0.8`） | 滑动不振动 | 持续 |
| 越界回弹 | 超出边界阻尼增强 + 橡皮筋回弹 | 滑动到边界轻触 | 持续 |

### 5.4 列表滚动「高级感」校准

| 参数 | 目标值 |
|------|--------|
| 滚动阻尼 | 0.7（适度阻尼，不飘不涩） |
| 惯性滑动 | 设备默认惯性（ArkUI `Scroll` 默认行为） |
| 越界回弹强度 | `edgeEffect: EdgeEffect.Spring` |
| 列表项滑动删除 | 跟手 + 删除按钮渐显（300ms） |
| 分隔线缩进 | 首项从左侧 16dp 起始（非全宽），视觉更轻盈 |

### 5.5 庆祝动效（Designed Moments）

> 在关键成就时刻触发全屏动效，给用户惊喜感。鸿蒙 ArkUI Canvas 可实现粒子系统。

| 触发条件 | 动效描述 | 时长 |
|---------|---------|------|
| 学完一个阶段（全部章节标记完成） | 底部慢升起 20-30 个半透明光点（升腾蓝 + 科技青），扩散消失 → 中央浮现阶段徽章（`scale 0→1.2→1` 弹簧效果） | 1.2s |
| 全部六阶段学完 | 全屏粒子升起 + "昇腾入门"证书卡片翻转展示 + 右上角飘落花瓣 | 2s |
| 收藏第 10 篇文章 | Toast + 图标特殊脉冲（放大 + 发光） | 0.8s |
| 第一次打开 APP（仅一次） | 引导页最后一张卡片 → 首页渐变展开 | 0.5s |

### 5.6 加载/空状态"无感知设计"

| 状态 | 设计策略 |
|------|---------|
| 首页加载 | **无加载过程** — 内容全部本地，首页直接展示完整内容，不使用骨架屏 |
| 搜索 | **无需加载** — 本地索引毫秒返回结果，不加"加载中"指示器 |
| 空结果 | 展示示例关键词推荐 + 插画，**不展示加载圈** |
| 收藏夹为空 | 空状态插画 + "去首页浏览"按钮，**不使用加载指示器** |
| 应用冷启动 | 启动图 = 品牌 Logo（深空蓝底色 + AscendMate Logo），无加载条 |
| 版本更新提示 | 仅在「关于页」展示当前内容版本号 + 检查更新入口（跳转应用市场） |

### 5.7 字体排印的精致感（Typography Polish）

| 规则 | 说明 |
|------|------|
| 中文标点全角 | 正文中应使用全角逗号句号，禁止半角混用 |
| 数字/英文 | 跟随 HarmonyOS Sans 默认宽高比（中文 1:1，英文 1:2） |
| 齐头尾 | 正文两端对齐（`textAlign: JUSTIFY`） |
| 悬挂标点 | 段首标点（引号）自动悬挂加 0.5em 推入 |
| 连字符止 | 代码块/URL 自动换行优先在 `/` `-` `_` 处换行 |
| 阅读宽度 | 每行 25-35 个汉字，最佳阅读宽度 > 40dp 边距 |
| 字间距 | 大标题 `letter-spacing: 1dp`，正文正常 |
| 标点调节 | 中文引号前后微调间距 `0.1em`，更舒适 |

## 7. 无障碍设计

- 所有可交互元素提供 `accessibilityLabel`
- 对比度 ≥ 4.5:1（正文）/ 3:1（大文本）
- 支持系统动态字体缩放适配
- 支持 TalkBack 屏幕阅读器
- 触控热区 ≥ 44×44dp
