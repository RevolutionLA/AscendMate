# 09 设计评审清单（交付给开发团队）

> 本清单用于设计定稿后的团队评审与开发前的最终确认。逐项核对，全部通过后才能进入编码阶段。

## 1. 产品层

- [ ] 产品定位明确：移动端昇腾资料阅览门户（不做运维实操）
- [ ] 目标用户与使用场景已达成共识（学习者/运维/算法/决策者）
- [ ] **P0 功能范围冻结（首页、浏览、搜索、导航、收藏——全部离线可用）**
- [ ] **全本地化战略确认：内容全部内置，不申请网络权限，更新靠版本发布**
- [ ] **消除陌生感设计纳入 P0（首次引导/示例词/零等待）**
- [ ] **UI 精致丝滑标准纳入验收（动效 60fps、毛玻璃、按压反馈）**
- [ ] 阶段划分（MVP → 增强 → 鸿蒙特性）确认

## 2. 信息架构层

- [ ] 底部 4 Tab 结构确认（首页/知识库/搜索/我的）
- [ ] 知识库三分类（学习/场景/资源）+ 技术导航映射确认
- [ ] 全部文章完成分类归属
- [ ] 文章详情页的上一篇/下一篇逻辑定义
- [ ] 目录结构可支持内容扩展（新增内容只需重构打包，无需改代码）
- [ ] 首页「继续阅读」数据来源（本地进度库）确认

## 3. 交互层

- [ ] 全局手势（侧滑返回/长按菜单，**无刷新下拉**）确认
- [ ] 所有页面转场动效时长记录（≤ 350ms）
- [ ] 空状态/错误状态有统一插画设计（**无网络类状态**）
- [ ] **首启引导页流程确认（3 页 + 跳过 + 立即开始）**
- [ ] **搜索框示例关键词点击即搜确认**
- [ ] **「继续阅读」进度恢复精确度确认（滚动位置级别）**
- [ ] 文章阅读进度保存时机确认（滚动停止 2s / 离开页面）
- [ ] 收藏/取消收藏反馈（Toast + 撤销 + 弹性动效）
- [ ] 键盘弹出输入框不被遮挡
- [ ] 触觉反馈触发点清单

## 4. 视觉层

- [ ] 色彩 Token 与深色模式映射表冻结
- [ ] 字体层级表确认（含阅读字号 4 档 + 排版精致规则）
- [ ] 间距体系（4 点网格）统一
- [ ] **毛玻璃规范参数冻结（背景不透明度/模糊量/分割线）**
- [ ] **动效曲线统一为 5 条，禁止自定义**
- [ ] **按压反馈/列表滚动阻尼/越界回弹参数冻结**
- [ ] 卡片/列表/按钮组件样式统一
- [ ] 代码块深浅配色方案确认
- [ ] 图标资源到位（Tab 4 套 × 2 态 + 功能图标）
- [ ] 品牌 Logo / 启动图 / 应用图标到位
- [ ] **引导页三页插画与大标题文案确认**

## 5. 鸿蒙特性层

- [ ] 桌面 Widget（2 款以上）尺寸与内容确认（**内容来自本地包**）
- [ ] 元服务范围确定（搜索 + 速览，同样全离线）
- [ ] 深色模式跟随系统方案确认
- [ ] 多端协同（分布式数据，非云）技术预研结论
- [ ] 意图框架（可选）接入范围确认
- [ ] 折叠屏/平板响应式布局策略确认
- [ ] **零权限设计确认（不申请 INTERNET）**

## 6. 技术层

- [ ] Markdown 渲染器选型确认（自研 ArkTS 渲染）
- [ ] 搜索方案（本地预构建倒排索引）确认
- [ ] **内容打包工具链确认（tools/*.js → rawfile）**
- [ ] **零网络架构确认（无 INTERNET 权限、无网络组件）**
- [ ] 数据存储方案（RDB/Preferences）确认
- [ ] 性能基线（冷启动 <0.5s / 渲染 <150ms / 搜索 <100ms）明确
- [ ] **权限清单 = 零权限** 确认
- [ ] ArkTS 工程结构模板创建

## 7. 交付流程

- [ ] 设计稿（Figma）交付完整标注
- [ ] 设计 Token JSON 导出
- [ ] 图标 SVG 资源打包
- [ ] 数据模型/接口伪代码评审
- [ ] 测试用例初稿完成（功能/兼容/性能/无障碍/**离线全功能**）
- [ ] 发布渠道（AGC）账号与签名准备
