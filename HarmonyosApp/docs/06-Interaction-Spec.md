# 06 交互设计规格

## 1. 交互设计原则

| 原则 | 说明 |
|------|------|
| **拇指域优化** | 高频操作按钮置于屏幕中下区域（拇指可及半径） |
| **可见性** | 关键功能一次点击可见，不藏在深层菜单 |
| **即时反馈** | 所有操作 100ms 内给出视觉反馈（本地化后应 < 50ms） |
| **可逆性** | 收藏/删除均有可撤销操作 |
| **容错性** | 搜索输入容错（错别字提示、联想纠正） |
| **零等待** | 全本地架构下无任何加载等待，交互即点即应 |
| **可预期** | 用户能预见每次点击的结果（方向感明确、路径清晰） |

### 1.1 新手零门槛交互策略（消除陌生感）

| 场景 | 交互设计 |
|------|---------|
| **首次启动** | 3 页横向滑屏引导卡片，最后一张带"立即开始"按钮（默认文案"开启昇腾之旅"） |
| **引导后首页** | 首页直接展示内容（无引导弹窗打扰），顶部搜索框自动获得一次"呼吸动效"提示（微光晕呼吸 2 次后停止） |
| **首次点击搜索框** | 自动展开预置示例关键词芯片（`npu-smi` `CANN安装` `FAQ`），点击任一即开始搜索 |
| **首次进入学习路径** | 展示"如何学"的小提示条（可关闭）：1. 请按阶段顺序学习 2. 每章读完自动标记 |
| **首次返回首页** | 顶部短暂显示白字条提示"下次可从首页「继续阅读」找回进度"，3 秒后消失 |
| **识别老用户** | 用户完成 ≥5 次阅读后，引导类提示不再出现（`guideTipsShown` 持久化） |

## 2. 手势体系

### 2.1 核心手势

| 手势 | 操作 |
|------|------|
| 单指点击 | 选择、打开 |
| 单指长按 | 弹出上下文菜单（收藏/分享/复制链接） |
| 单指滑动 | 页面滚动（阻尼效果） |
| 左滑 | 返回上一页（全局侧滑返回） |
| 右滑 | 前进（浏览历史） |
| 双指缩放 | 图片查看、代码块放大 |
| 下拉 | 无刷新（全离线无需刷新），可触发「返回顶部」 |

### 2.2 手势与页面映射

| 页面 | 手势行为 |
|------|----------|
| 首页 | 下拉不动（无网络刷新），但可下拉查看「最近更新内容」排序切换（可选） |
| 文章详情 | 左滑返回；下滑调出目录浮层（边缘触发） |
| 列表页 | 长按文章项 → 弹出操作菜单 |
| 搜索页 | 清空按钮 X；下滑收起键盘 |
| 我的 | 长按收藏条目 → 弹出菜单（删除/移动收藏夹） |

## 3. 导航模型

### 3.1 Tab 导航行为

| 行为 | 实现 |
|------|------|
| Tab 点击 | 切换页面 + 触感反馈 + 淡入动效 |
| 当前 Tab 双击 | 回滚到页面顶部 |
| 当前 Tab 再点击（已顶部） | 无操作（在线刷新不适用于离线 APP） |
| Tab 长按 | 显示快捷操作（首页→搜索；知识库→最近浏览） |
| Tab 切换动效 | 标签页切换时右侧新页从右滑入、左侧旧页向左滑出，给用户明确方向感（← →） |

### 3.2 页面栈

```
[Navigation] 鸿蒙系统路由
├── 首页 (根)
│   ├── 分类列表
│   │   └── 文章详情
│   └── 搜索结果 → 文章详情
├── 知识库 (根)
│   ├── 分类详细页
│   └── 学习路径 → 学习详情
├── 搜索 (根)
│   └── 搜索结果 → 文章详情
└── 我的 (根)
    ├── 收藏夹 → 文章详情
    ├── 阅读历史 → 文章详情
    ├── 学习进度 → 学习详情
    ├── 设置 → 阅读设置/关于
    └── 离线缓存 → 管理页
```

## 4. 关键交互流程

### 4.1 搜索流程（消除陌生感版）

```
搜索框默认显示示例词（"npu-smi" "CANN安装" "FAQ"）
用户点击搜索框
    ↓
搜索框自动展开（过渡动效 200ms），预置示例关键词作为可点击芯片（chip）
    ├─ 用户点击示例 → 直接搜索该词
    └─ 用户输入关键词 → 实时联想（防抖 150ms，本地索引毫秒级匹配）
    ↓
展示结果（标题+摘要+路径+关键词高亮）
    ├─ 结果过多 → 顶部分类筛选标签（全部/环境/训练/推理...）
    ├─ 无结果 → 示例词推荐 + "换个关键词试试"
    └─ 所有结果均来自本地包，**无加载状态**
    ↓
点击结果 → 文章详情（关键词滚动定位并高亮 3 秒）
```

### 4.2 学习路径流程

```
首页宫格点击「学习」
    ↓
学习路径总览（六阶段进度环）
    ↓
点击阶段卡 → 阶段详情页（章节列表 + 完成状态）
    ↓
点击章节 → 文章阅读
    ├─ 阅读完毕（滑到底部）→ 弹「标记为已完成？」确认
    ↓
返回阶段页 → 章节显示 ✓，进度更新
    ↓
六阶段全部完成 → 学习证书页面（可分享）
```

### 4.3 收藏流程

```
文章页面 → 点击底栏 ♡
    ↓
未创建收藏夹 → 弹「新建收藏夹」输入框（默认名「默认收藏夹」）
    ↓
已创建 → 直接收藏（Toast「已收藏」）或弹选择收藏夹
    ↓
再次点击 ♡ → 取消收藏（Toast「已取消」+「撤销」按钮 3 秒）
```

## 5. 状态反馈

### 5.1 加载状态（全离线 = 几乎无加载）

| 状态 | 表现 |
|------|------|
| 首页/列表/搜索 | **无加载** — 内容全部本地，直接渲染（无骨架屏） |
| 首次冷启动 | 启动图（品牌 Logo）快速直出首页 |
| 大文档渲染（极少数 >100KB） | 局部骨架：标题先显示，正文渐显（< 100ms） |
| 收藏/进度写入 | 瞬时完成，无指示（< 20ms） |

### 5.2 空状态 & 错误状态

| 状态 | 插画 + 文案 | 操作 | 备注（全本地后含义变化） |
|------|-----------|------|--------------------------|
| 无搜索结果 | 放大镜+「未找到相关内容」 | 展示示例搜索词，"换个关键词试试" | 搜索范围：已安装的内容（所有内容） |
| 收藏夹为空 | 空星星+「还没有收藏的内容」 | 「去首页浏览」按钮 | |
| 加载失败 | 感叹号+「数据异常」 | 「重启 APP」按钮 | **不再有「网络已断开」** — APP 不需要网络 |
| 阅读历史为空 | 时钟+「还没有阅读记录」 | 「去首页看看」 | |

## 6. 触觉反馈

| 触发 | 反馈 |
|------|------|
| Tab 切换 | 轻触觉（`Haptics.Impact.Light`） |
| 收藏/下载成功 | 中触觉 + 伴随音效 |
| 错误操作 | 重触觉（`Haptics.Impact.Heavy`） |
| 长按呼出菜单 | 轻触觉 |

## 7. 无障碍交互

- 全功能支持键盘导航（外接键盘方向键+TAB）
- 动态字体（系统字体缩放 100%-200% 内容不破坏）
- 对比度适配（见 03 无障碍设计）
- 交互目标最小尺寸 44×44dp（代码块复制按钮 40dp 可忽略）

## 8. 交互验收清单

- [ ] 所有底部操作在单手模式下可触达（拇指域）
- [ ] 页面转场无明显卡顿（< 16ms 帧渲染）
- [ ] 搜索响应 < 100ms（本地索引验证）
- [ ] 冷启动 < 0.5s 直接显示首页完整内容
- [ ] 无网络权限下所有功能正常可用（INTENT 权限不申请）
- [ ] 首次打开引导页 → 首页过渡流畅无闪烁
- [ ] 搜索框默认显示示例关键词，点击即搜
- [ ] 阅读进度即使强制退出也能恢复
- [ ] 键盘弹出时输入框不被遮挡（`adjustPan` 模式）
- [ ] 深色模式切换无闪烁
- [ ] 动效帧率：页面转场/滚动全程 60fps
- [ ] 按钮按压缩放动效 100ms 内响应
- [ ] 空状态均为自定义插画，无原生空白页
- [ ] 收藏操作可撤销（Toast 常驻 3s）
- [ ] 首次用户的引导提示在完成 5 次阅读后不再出现
