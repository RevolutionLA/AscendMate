把昇腾相关的官方平台与开源社区集中整理在一起，按需进入。

## 五、使用建议

- **寻求帮助**：优先查 [业务问题 FAQ](/faq/)，再到对应开源项目的 GitHub/GitCode **Issues** 提交。
- **参会交流**：vLLM-Ascend 等社区有**周例会**，关注其 README 中的会议链接。
- **获取最新**：刷昇腾社区官网「动态新闻」与公众号。

> [!NOTE]
> 各社区链接为公开资源，须遵守其平台规则与代码仓库的许可证。本仓库不替代各种官方社区，仅做入口导航。
