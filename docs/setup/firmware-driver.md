# 03 固件与驱动安装

> **什么时候读**：系统装好后，需要让操作系统识别到 NPU 设备。

固件（Firmware）与驱动（Driver）是昇腾 NPU 被系统识别和驱动的底层软件，通常打包在**同一个升级包**里一起安装。安装顺序与版本配套极其重要。

## 一、获取安装包

- 社区版：昇腾社区「固件与驱动」下载页（CANN 下载站内）。
- 选包时**必须匹配你的硬件型号 / 操作系统 / 架构**，并尽量与目标 CANN 版本配套。

下载入口汇总见 [资源导航 - 软件下载](/resources/download)。

## 二、安装前置检查

```bash
# 确认 OS 与架构
uname -a

# 检查是否有已存在驱动/残留（若之前装过）
ls /usr/local/Ascend/driver 2>/dev/null && echo "已有驱动目录"

# 确认无内核模块冲突（可选）
rmmod npu_smi 2>/dev/null
```

> [!WARNING]
> 若机器之前装过其他版本驱动，需要先**干净卸载**，避免残留导致新驱动起不来。

## 三、安装固件和驱动（run 包方式）

以安装命令示例（请把 `<包名.run>` 换成实际包名）：

```bash
# 切换 root 或有 sudo
sudo chmod +x ./Ascend-hdk-<版本>-<os>-aarch64.run
sudo ./Ascend-hdk-<版本>-<os>-aarch64.run --upgrade

# 或使用 --full 全量安装
sudo ./Ascend-hdk-<版本>-<os>-aarch64.run --full
```

安装完成后，默认安装在 `/usr/local/Ascend`。部分版本还需：

```bash
# 加载内核模块（新内核可能需重启后自动加载）
lsmod | grep npu_smi
```

## 四、验证是否识别设备

```bash
npu-smi info
```

理想输出应包括：

- 驱动版本
- 每张 NPU 卡的型号、健康状态、温度、内存

```
npu-smi info
+------------------------------------------------------------------------------------+
| npu-smi 24.x.x                       Driver Version: 24.x.x                         |
+-------------------------------+-----------------+-----------------+------------------+
| NPU Name                      | HBM-Usage       | HBM-Util       | Temperature      |
+---[model]---------------------+-----------------+-----------------+------------------+
| 0  Atlas 800I A2 ...          |   0 /   ... GB  |    0%          |     35 C         |
+-------------------------------+-----------------+-----------------+------------------+
```

见不到设备（`npu-smi info` 报错或为空）时，排查 [环境搭建类问题](/faq/setup-issues)。

## 五、说明

- 固件驱动升级包常以 **Ascend-hdk-...** 或 **A800-...-driver** 等命名。
- 驱动和固件配套关系更新频繁，**务必以你选定 CANN 版本对应的发布说明为准**。

## 验证

`npu-smi info` 能正确列出设备 → 进入 [04 CANN 安装](/setup/cann-install)。
