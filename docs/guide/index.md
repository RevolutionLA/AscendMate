## 三条主路

依据你的目标，走对应的路：

### 路线 A：交付一台整机 ✅

从裸机到可跑业务，照着 [7 步走](/guide/seven-steps) 一路做。

### 路线 B：把模型跑起来

- **微调**：环境 → [LLaMA-Factory 微调实操](/training/llama-factory)
- **推理服务**：环境 → [MindIE](/inference/mindie) 或 [vLLM-Ascend](/inference/vllm-ascend)

### 路线 C：GPU 老用户迁移昇腾

先理解对应关系（见 [昇腾全景](/guide/ascend-landscape) 的对照表），再按 [PyTorch 模型迁移](/training/pytorch-migration) 操作。
