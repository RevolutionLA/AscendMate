# 快速开始

> 从这里开始，选对路径，少走弯路。

## 先弄清楚你要做什么

- 不确定从哪入手？→ [如何选择使用路径](https://revolutionla.github.io/AscendMate/guide/choose-your-path)
- 不知道昇腾能干嘛？→ [典型部署场景](https://revolutionla.github.io/AscendMate/guide/use-cases)
- 第一次拿到智算服务器？→ [从零到上手：7 步走](https://revolutionla.github.io/AscendMate/guide/seven-steps)
- 想看全局？→ [昇腾软硬件全景](https://revolutionla.github.io/AscendMate/guide/ascend-landscape)
- 想先了解这个仓库能怎么帮你？→ [认识 AscendMate](https://revolutionla.github.io/AscendMate/guide/what-is-ascendmate)

## 三条主路

依据你的目标，走对应的路：

### 路线 A：交付一台整机 ✅

从裸机到可跑业务，照着 [7 步走](https://revolutionla.github.io/AscendMate/guide/seven-steps) 一路做。

### 路线 B：把模型跑起来

- **微调**：环境 → [LLaMA-Factory 微调实操](https://revolutionla.github.io/AscendMate/training/llama-factory)
- **推理服务**：环境 → [MindIE](https://revolutionla.github.io/AscendMate/inference/mindie) 或 [vLLM-Ascend](https://revolutionla.github.io/AscendMate/inference/vllm-ascend)

### 路线 C：GPU 老用户迁移昇腾

先理解对应关系（见 [昇腾全景](https://revolutionla.github.io/AscendMate/guide/ascend-landscape) 的对照表），再按 [PyTorch 模型迁移](https://revolutionla.github.io/AscendMate/training/pytorch-migration) 操作。
