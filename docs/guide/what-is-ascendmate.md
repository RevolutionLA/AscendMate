# 认识 AscendMate

> **一句话定位**：面向昇腾智算服务器部署与开发的一站式手册，覆盖从环境搭建到业务上线的具体操作与检索入口。

## AscendMate 想解决什么问题

昇腾生态在快速成熟，但对最终用户来说，信息仍然存在几个痛点：

1. **资料分散**：官方文档在 `hiascend.com`、`support.huawei.com`、Gitee/GitCode/GitHub 等多个站点，格式从 PDF、DOCX 到 Markdown 不一。
2. **结构深**：官方文档层级深、术语多，新手往往不知道从哪一步开始。
3. **场景不直观**：用户关注的是「我要跑个大模型」「我要做推理服务」，而不是「CANN 8.x 的安装指南第 3 节」。
4. **易用性**：缺一份面向真实交付场景、可照着做的操作手册。

AscendMate 把这些散落的资料，整理成**按真实场景组织**的、**可全文检索**的、**带实操步骤**的指南，让用户按自己的角色和诉求快速定位。

## 仓库里有什么

```text
AscendMate/
├── README.md                 # 仓库说明与快速链接
├── docs/                     # 文档站（VitePress 驱动）
│   ├── index.md              # 首页
│   ├── guide/                # 快速开始：怎么选路径、7步走
│   ├── setup/                # 环境搭建（系统/驱动/CANN/框架）
│   ├── hardware/             # 昇腾硬件选型与文档
│   ├── training/             # 大模型训练（微调/迁移）
│   ├── inference/            # 模型推理（MindIE/vLLM/SGLang）
│   ├── ops/                  # 算子开发（Ascend C/Triton）
│   ├── tools/                # 工具链（MindStudio/调优）
│   ├── resources/            # 资源导航（完整链接总表）
│   ├── faq/                  # 问题定位（FAQ）
│   └── contributing/         # 贡献指南
└── ...                       # 站点配置文件等
```

## 怎么使用这个仓库

- **想快速开始**：看 [从零到上手：7 步走](/guide/seven-steps)。
- **不确定从哪入手**：看 [如何选择使用路径](/guide/choose-your-path)，按角色/场景对号入座。
- **想找某个特定内容**：用页面右上角的**搜索框**，输入关键词直接搜。
- **想看完整清单**：去 [资源导航总表](/resources/links)。

## 本仓库不是

- ❌ 不是官方文档的搬运堆砌 —— 而是**面向交付场景**的重新组织和实操指引。
- ❌ 不能替代官方最新版本 —— 链接会指向官方权威源，请以官方为准。
- ❌ 不做商务报价 —— 硬件选型会给参考，但具体配置与价格请咨询对应销售。
